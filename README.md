# Customer Segmentation 
live now: [https://customer-segmentation-ml-6.onrender.com/]




🧠 Customer Segmentation using Machine Learning

AI-powered customer profiling for smarter business decisions




📌 Project Overview

This project is an end-to-end Machine Learning web application that segments customers into meaningful groups based on their demographic and behavioral data.

Businesses can use this system to:

Identify high-value customers

Detect at-risk users

Personalize marketing strategies

Improve customer retention and revenue

The application uses unsupervised learning (KMeans clustering) and is deployed as a Flask web service.



🚀 Live Features

🔍 Predict customer segment using ML

📊 Automatically assign customer personas

🗂 Store prediction history in SQLite database

📄 Generate downloadable PDF reports

🌐 REST API support

☁️ Cloud-ready (Render compatible)

🧠 Machine Learning Approach
🔹 Algorithm Used

KMeans Clustering (Unsupervised Learning)

🔹 Why KMeans?

No labeled data required

Efficient for numerical customer features

Widely used in real-world customer segmentation problems

📥 Input Features
Feature	Description
Income	Annual income of the customer
Age	Age of the customer
Total_Spending	Total money spent
Recency	Days since last purchase


🎯 Output

The model predicts:

Cluster ID (numeric)

Customer Persona (human-readable segment)

Example Personas

Premium Loyalists

Budget Active Shoppers

At-Risk Customers

Loyal Seniors
